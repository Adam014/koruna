# Requirements

The task brief, restated as checkable requirements. This file is
the source of truth for scope: if something is not needed for one of these, it is
out of scope.

| #   | Requirement (from the brief)                                                                                                                                                                                  | What it means here                                                                                                                                                   |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | On start, retrieve the latest rates from the CNB [`daily.txt`](https://www.cnb.cz/en/financial-markets/foreign-exchange-market/central-bank-exchange-rate-fixing/central-bank-exchange-rate-fixing/daily.txt) | Fetched via the same-origin Worker `GET /api/rates` (CNB has no usable CORS), which returns JSON                                                                     |
| R2  | Parse the data and clearly display a list in the UI                                                                                                                                                           | Parser follows the [CNB format docs](https://www.cnb.cz/en/faq/Format-of-the-foreign-exchange-market-rates/) and the real file; show the fixing date from the header |
| R3  | A form: amount in CZK + currency → converted amount (on submit or in real time)                                                                                                                               | Real time; `czk * amount / rate`; formatted with `Intl.NumberFormat`                                                                                                 |
| R4  | Commit throughout the work, code on GitHub                                                                                                                                                                    | Small Conventional Commits on `main`, repo `Adam014/koruna`                                                                                                          |
| R5  | Deploy so it can be viewed online                                                                                                                                                                             | Cloudflare Worker at https://momence.stadnik.dev, deployed from CI after checks pass                                                                                 |
| R6  | Automated tests that ensure the solution works                                                                                                                                                                | Unit tests for parser and conversion, Worker tests, one end-to-end test of the main flow                                                                             |
| R7  | Stack: React (+ Hooks), TypeScript, Styled Components, React Query                                                                                                                                            | No Next.js; no other UI or state libraries                                                                                                                           |

Overall: keep the code simple and the UI nice and easy to use.
